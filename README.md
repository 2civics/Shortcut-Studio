# Shortcut-Studio
Shortcut Studio is a lightweight Windows 11 PowerShell &amp; WPF tool to create Desktop shortcuts for Microsoft Store (UWP/MSIX) apps, executables, folders, and URLs. Features Auto/Dark/Light Fluent UI, UAC elevation, live Shell icon extraction, and a visual icon grid picker. Works natively on PowerShell 5.1 &amp; 7.x.
